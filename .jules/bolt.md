## 2025-05-18 - Fast String Prefix Normalization for Directory Walking
**Learning:** Instantiating `pathlib.Path` and calling `.relative_to()` inside `os.walk()` loops across thousands of files introduces substantial object instantiation overhead (~35ms per scan). Replacing `Path` creation with `os.path.join`, string slicing, and strict trailing-separator prefix matching (`root_prefix = root_str if root_str.endswith(os.sep) else root_str + os.sep`) yields an ~91% performance improvement (~3ms per scan) while cleanly maintaining boundary safety against sibling directory prefix clashes.
**Action:** When performing recursive filesystem walks over workspace trees, prefer raw string path operations with trailing directory separator boundary checks over per-file `pathlib.Path` instantiation.
